# Flask Demo

## Prérequis
Python3.12

## Installation

```bash
# Cloner le projet
git clone https://github.com/aymlpz92/flask-demo

# Créer l'environnement virtuel
python -m venv .venv
source .venv/Scripts/activate

# Installer Flask
pip install Flask
```

## Lancement du serveur

```bash
flask --app app run --port 5050
```
